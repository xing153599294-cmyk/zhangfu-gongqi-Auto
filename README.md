# 掌赋工期 · 配置后台

一个纯前端的后台原型，用于制作和管理「工期模板」：把整套施工流程拆成节点，配置每个节点的施工天数与前置关系，并以关系图 + 关键路径算法自动推算总工期。

## 已实现能力

- **工期模板管理**：新建、复制、启用/停用、删除、搜索筛选。
- **节点配置**：每个模板第一个节点固定为「开工」，不可删除、不可改名、天数固定为 0。
- **前置关系**：多选前置节点，系统自动检测并屏蔽会导致循环依赖的选项。
- **关系图**：SVG 分层布局，从左到右展示节点与依赖；支持拖拽节点、滚轮缩放、复位/全屏。
- **工期测算**：基于关键路径法（CPM）自动计算总工期、关键路径、各节点最早/最晚开始时间；填写计划起始日期后可推算预计完工日。
- **异常提示**：循环依赖红条告警、无前置节点黄条提示、完全孤立节点提示。
- **工期应用**：挑选模板 → 勾选实际项目存在的节点 → 系统按规则自动推导前置关系并输出新的关系图与工期。
  - 前置节点缺失时，向上追溯「前置的前置」，直到找到存在的节点。
  - 追溯到的前置若同时是「另一个前置的前置」，则视为传递冗余，省略该前置关系。
  - 节点开始时间 = 所有前置结束时间的最大值。
  - 节点结束时间 = 开始时间 + 施工天数。

## 文件结构

- `index.html`：入口页与后台骨架
- `css/style.css`：样式系统
- `js/data.js`：种子模板数据
- `js/store.js`：本地数据持久化与模板/节点 CRUD、工期应用配置持久化
- `js/graph.js`：关键路径计算、分层布局、SVG 渲染、拖拽缩放
- `js/apply-calc.js`：工期应用推导算法（穿透缺失前置 + 传递冗余消除 + 时间计算）
- `js/ui.js`：通用工具与线性图标
- `js/pages/templates.js`：模板列表页
- `js/pages/editor.js`：模板编辑页
- `js/pages/apply.js`：工期应用页
- `js/pages/help.js`：配置规则说明页
- `js/app.js`：路由

## 本地预览

直接用浏览器打开 `index.html` 即可。所有数据保存在浏览器 localStorage 中，首次打开会自动写入 3 个示例模板。
